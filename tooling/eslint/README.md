# @bricx/eslint-config

The one ESLint flat config for BRICX IQ. The root `eslint.config.mjs` calls
`bricxConfig({ rootDir })`; every workspace package runs `eslint . --max-warnings 0`
from its `lint` script and picks up that root file.

| Block                                   | What it enforces                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `@eslint/js` recommended                | ESLint core rules on TS and JS/.mjs files                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| typescript-eslint `strict-type-checked` | Strict, type-aware rules; JS files are type-checked through `checkJs`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `boundaries/dependencies`               | `packages/*` never import `apps/*`; `packages/domain/src` imports only its own files and `data/`, `@bricx/ids`, `@bricx/money` and, for types only, `@bricx/i18n` (no other package, npm module or `node:` built-in; ADR 0049); `packages/validation/src` imports only `@bricx/ids`, `@bricx/money`, `@bricx/i18n`, its own `data/` and `zod`, and is the only package with validation → money and validation → i18n edges (ids, money, i18n and domain may not import it; money and i18n may not import each other; ADR 0047); `packages/permissions/src` imports only `@bricx/ids`, `@casl/ability` and its own files, plus `@bricx/i18n` for types only (ids, money, i18n, validation and domain may not import it; ADR 0048); an api module imports another module only via its `public-api.ts` |
| `no-restricted-syntax` (money)          | No `parseFloat`, `parseInt`, `Number`, `Number.parseFloat` or `Number.parseInt` on an identifier or property matching `/amount\|price\|total/i`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Domain clock                            | In `packages/domain/src`: no `Date.now()` and no zero-argument `new Date()`; use the injected `Clock` (ADR 0049)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `bricx/nest-modules`                    | In `apps/{api,worker}`: `@typescript-eslint/no-extraneous-class` allows a class with a decorator (Nest modules such as `@Module({...}) export class AppModule {}`); an undecorated static-only class still fails (ADR 0051)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `eslint-config-prettier`                | Turns off rules that fight Prettier                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Linter options                          | Unused `eslint-disable` comments are errors                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |

Every rule has a violation fixture and an allowed control in
[`tooling/eslint-smoke`](../eslint-smoke/README.md).

Turbo lint inputs include `tooling/eslint/*.{mjs,json}`, so changing a rule or
a plugin version invalidates every package's lint cache.
